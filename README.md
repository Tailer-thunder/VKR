# ВКР: образовательная резильентность школ

**Тема:** «Математическое моделирование и прогнозирование динамики образовательной резильентности школ на основе многомерных временных рядов аттестаций».

## Состояние проекта

Проект находится на этапе постановки задачи и подготовки методики исследования. Ниже описан план работы. Источник данных, состав предметов и период наблюдения уточняются. Код, инструкции запуска и результаты экспериментов будут добавляться по мере выполнения исследования.

## Цель

Разработать и экспериментально оценить подход к выявлению резильентных школ и прогнозированию устойчивости их образовательных траекторий по результатам аттестаций за несколько периодов.

Рабочее определение: **резильентная школа работает в неблагоприятных социально-экономических условиях и устойчиво превышает результаты, ожидаемые для сопоставимых условий обучения**. Показатели неблагоприятного контекста, пороги и число периодов устойчивости определяются до итогового тестирования.

## Задачи

1. Изучить литературу и уточнить критерии резильентности школ.
2. Подготовить многомерные ряды аттестаций и характеристики условий обучения.
3. Оценить ожидаемые результаты и остатки регрессионной модели.
4. Сгруппировать похожие траектории и выявить резильентные школы.
5. Построить и сравнить модели прогноза образовательных траекторий.
6. Проверить устойчивость групп и точность прогноза на последующих периодах.

## Данные

Единица анализа — школа. Временной шаг — период аттестации. Измерения ряда — показатели по выбранным учебным предметам.

Планируемые входные данные:

| Данные | Назначение |
| --- | --- |
| Обезличенный идентификатор школы | Связь наблюдений одной школы во времени |
| Период аттестации и предмет | Формирование многомерного временного ряда |
| Результаты аттестаций | Описание образовательной траектории |

Перед анализом необходимо проверить сопоставимость классов, шкал оценивания и процедур аттестации, обработать пропуски и учесть изменения контингента. В публичном репозитории предполагается размещать только данные, разрешённые к распространению, и обезличенные примеры.

## Метод исследования

### Оценка результатов с учётом условий

Регрессионная модель оценивает ожидаемый результат по доступным показателям исходной подготовки и условий обучения.

**Остаток = фактический результат − ожидаемый результат.**

Положительный остаток означает результат выше ожидаемого при заданных признаках. Остатки по предметам формируют многомерную траекторию школы.

Если доступны связанные индивидуальные результаты учащихся, оценки можно получать на этом уровне и затем агрегировать по школе. Если доступны только школьные показатели, применяется контекстная регрессия по агрегированным данным. Без достаточных сведений о предшествующей подготовке остатки нельзя считать полноценной оценкой образовательного прироста в смысле подхода *Value-Added*. Причинный вклад школы по таким остаткам не устанавливается.

### Кластеризация траекторий

Планируется использовать **DTW K-Means**:

- **DTW (Dynamic Time Warping)** — динамическое выравнивание временных рядов для сравнения траекторий.
- **K-Means** — метод k-средних для группировки похожих объектов.

Ограничение временного выравнивания подбирается с учётом календарного смысла наблюдений. Резильентную группу определяет содержательный критерий неблагоприятных условий и устойчивого превышения ожидаемых результатов. Сам по себе высокий центр кластера не означает резильентность.

Изменение состава группы изучается по последовательным временным окнам. При повторной кластеризации группы сопоставляются по характеристикам траекторий, поскольку номера кластеров могут меняться.

### Прогнозирование

Планируется сравнить две архитектуры рекуррентных нейронных сетей:

- **LSTM (Long Short-Term Memory)** — сеть долгой краткосрочной памяти.
- **GRU (Gated Recurrent Unit)** — управляемый рекуррентный блок.

Основной горизонт прогноза — один период аттестации. После прогноза показателей применяется установленный критерий, чтобы оценить сохранение статуса школы. Для коротких рядов предполагается совместное обучение на траекториях нескольких школ и ограничение сложности сетей.

## Проверка качества

- Обучение, настройка и тестирование следуют хронологическому порядку.
- Заполнение пропусков, масштабирование, регрессия и кластеризация обучаются без использования будущих наблюдений.
- Качество кластеризации оценивается коэффициентом силуэта по матрице расстояний DTW, стабильностью состава групп и чувствительностью к параметрам.
- Численный прогноз оценивается по **MAE (Mean Absolute Error)**, средней абсолютной ошибке, и **RMSE (Root Mean Squared Error)**, корню из средней квадратичной ошибки.
- Базовые прогнозы — последнее наблюдаемое значение и линейная модель с лагами. Все модели сравниваются на одинаковой выборке и горизонте.
- Точность прогнозируемого сохранения статуса школы проверяется отдельно от численной ошибки.

Преимущество LSTM или GRU должно подтверждаться экспериментом. При достаточной длине рядов дополнительно применяется скользящее тестирование с расширением обучающего периода.

## Ожидаемые результаты и применение

Планируется получить подготовленные ряды аттестаций, критерий резильентности, группы школьных траекторий, сравнительную оценку прогнозных моделей и прототип с графиками траекторий и прогнозов.

Результаты могут использоваться исследователями образования и специалистами по сопровождению школ для мониторинга устойчивых результатов, выявления признаков ухудшения и аналитической поддержки адресной помощи.

## Границы работы и перспективы

Текущая работа ограничена доступными данными выбранных периодов и предметов, прогнозом на один период и сравнением моделей. Причинная оценка мер поддержки и внедрение в действующие информационные системы выходят за текущий объём.

Перспективы: расширение данных на другие регионы и периоды, прогноз на несколько периодов и отдельное исследование мер поддержки при наличии необходимых данных.
